# Restaurant Digital Menu & Ordering UI/UX Design

This project is a UI/UX design prototype for a restaurant digital menu and food ordering system.
It was created as part of a UI/UX Design Internship task.

## Project Overview
The goal of this project is to design an intuitive interface where users can:
- Browse food items by category
- View food images, prices, and descriptions
- Add items to a cart
- Proceed to checkout

## Features Designed
- Category-based menu
- Food cards with images and pricing
- Order cart and checkout flow
- Mobile-first UI design
- Figma prototyping and interactions

## Tools Used
- Figma
- Unsplash / Freepik
- Google Fonts
